# CloudOps Studio Homebrew Tap

Official Homebrew tap for CloudOps Studio command-line tools.

## Installation

```bash
brew tap cloudopstudio/tap
brew install cloudops-dots
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| `cloudops-dots` | Interactive TUI installer for CloudOps.Dots dev environment |

## Updating

```bash
brew update
brew upgrade cloudops-dots
```
